# Nómina mensual en Java — Práctica 11

Aplicación de consola para registrar empleados fijos y por hora, calcular pagos e imprimir el reporte mensual.

## Compilar y ejecutar
Desde esta carpeta, ejecuta:

```bash
javac -d out src/modelo/Empleado.java src/modelo/EmpleadoFijo.java src/modelo/EmpleadoPorHora.java src/aplicacion/Main.java
java -cp out aplicacion.Main
```

Consulta `EXPLICACION_CONCEPTOS.txt` para la explicación de los conceptos requeridos.
